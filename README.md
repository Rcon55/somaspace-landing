# SomaSpace — лендинг

Статическая вёрстка лендинга SomaSpace, перенесённая из Tilda (`boldly-contrary-weasel.tilda.ws`) в обычные HTML/CSS/JS без зависимостей и сборки.

## Структура

```
index.html              главная страница
eula/                   условия использования        → /eula/
pdn_policy/             политика конфиденциальности  → /pdn_policy/
cookie_policy/          политика cookie              → /cookie_policy/
consent_pnd/            согласие на обработку ПД     → /consent_pnd/
payment/                условия оплаты               → /payment/
404.html                страница «не найдено»
favicon.svg, robots.txt, sitemap.xml
assets/
  css/style.css         все стили сайта
  css/legal.css         дополнения для юридических страниц
  js/main.js            шапка, анимации, попап с формой, cookie-баннер
  js/legal.js           загрузка текста документов с API
  img/                  изображения (фото в WebP, графика в SVG)
```

Каждая юридическая страница лежит в своей папке как `index.html`, поэтому адреса вида `/eula/` работают на любом статическом хостинге без правил переписывания URL.

## Локальный запуск

Нужен любой локальный сервер (если открыть `index.html` двойным кликом, ссылки на папки работать не будут):

```bash
python3 -m http.server 8000
# или
npx serve .
```

Затем откройте http://localhost:8000.

## Как устроена вёрстка

**Масштаб.** Как и в Tilda, макет пропорционально тянется вместе с окном. `1rem` = 10px макета:

- до 1023px — мобильная сетка 360px (`html { font-size: 100vw / 36 }`, на планшетах не больше 16px, колонка по центру);
- от 1024px — десктопная сетка 1280px (`html { font-size: 100vw / 128 }`, не больше 15px).

То есть «14px из макета» в CSS пишется как `1.4rem`.

**Композиции.** Свободные композиции (первый экран, блок «люди и процессы», кривая с решениями) на десктопе позиционируются по координатам из макета прямо в разметке:

```html
<img style="--x:273; --y:388; --w:409; --h:276">   <!-- десктоп, сетка 1280 -->
<div style="--mx:10; --my:224; --mw:300">           <!-- мобильная версия, сетка 360 -->
```

Чтобы сдвинуть элемент, поменяйте числа: это пиксели макета. Остальные блоки (карточки, подвал, попап, cookie-баннер) свёрстаны обычным потоком на Flexbox и Grid.

**Цвета и шрифт** заданы переменными в начале `style.css` (`--ink`, `--bg`, `--muted`…). Шрифт Inter подключается из Google Fonts.

**Анимации** задаются data-атрибутами (подробности в комментариях в `main.js`):

| атрибут | что делает |
|---|---|
| `data-reveal` | плавное появление снизу при прокрутке |
| `data-parallax="k"` | параллакс (по умолчанию только на десктопе) |
| `data-drift="k"` + `data-drift-max` | сдвиг вместе с прокруткой на первом экране |
| `data-pin="px"` | элемент «прилипает» на заданное расстояние |
| `data-grow` | вертикальная линия вырастает при прокрутке |

Если в системе включено «уменьшение движения» (`prefers-reduced-motion`), анимации отключаются.

## Что нужно настроить

1. **Отправка формы «связаться».** В Tilda заявки уходили на сервер Tilda, здесь его нет. Укажите адрес своего обработчика в `assets/js/main.js`:
   ```js
   const CONFIG = { formEndpoint: 'https://somaspace.ru/api/…', … }
   ```
   Форма отправляет `POST` с JSON `{ name, inn, phone, email, page }` и ждёт ответ 2xx. Подойдёт свой API, Formspree, Web3Forms или бот в Telegram через небольшой бэкенд. Пока адрес пустой, форма показывает ошибку и выводит данные в консоль.
2. **Домен.** В `index.html` и юридических страницах (`canonical`, `og:url`), а также в `sitemap.xml` и `robots.txt` указан `https://somaspace.ru`. Если лендинг будет жить на другом домене, замените.
3. **Юридические документы** подгружаются с `/api/v1/legals/get-legals` (так же, как в Tilda). Это работает, только если сайт размещён на том же домене, что и API. На другом домене нужен абсолютный адрес API в `assets/js/legal.js` и CORS на сервере.
4. **Аналитика.** Счётчиков в исходной странице не было. Если добавите Метрику и т.п., подключайте её после согласия на cookie:
   ```js
   document.addEventListener('cookie-consent', (e) => {
     if (e.detail.analytics) { /* загрузить счётчик */ }
   });
   // при повторных визитах: window.somaConsent.get()
   ```

## Отличия от версии в Tilda

- Убраны jQuery, ~30 скриптов Tilda и плашка «Made on Tilda». Вес картинок снизился примерно с 3 МБ до 130 КБ (WebP).
- Попап сделан на нативном `<dialog>` (закрывается по Esc и клику по фону), его можно открыть ссылкой `#contact`.
- Добавлены маска телефона, валидация полей и защита от спам-ботов (скрытое поле).
- В подвале на десктопе e-mail больше не выходит за край экрана.
- В настройках cookie английские фразы Tilda («Cookies necessary…», «Confirm») переведены на русский.
- Пункт меню «мероприятия» ведёт на `#events`, но такого блока нет (в Tilda ссылка тоже вела на несуществующий блок). Добавьте секцию с `id="events"` или поменяйте ссылку.
- Для страны в поле телефона оставлен только код +7, без выпадающего списка стран.

## Публикация

Это обычная статика: подойдут GitHub Pages, Netlify, Vercel, Cloudflare Pages, S3 или nginx. Для nginx страницу 404 можно подключить так:

```nginx
error_page 404 /404.html;
```
